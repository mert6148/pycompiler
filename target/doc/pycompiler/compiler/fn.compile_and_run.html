Function compile_and_run 

Source 
pub fn compile_and_run(source: &str) -> Result<String, CompileError>
Expand description

Compiles and executes one Rusty source program.

Comparisons produce 1 for true and 0 for false. Any nonzero value is treated as true in if and while conditions.

§Examples

let output = compile_and_run("let answer = 6 * 7; print answer;")?;
assert_eq!(output, "42\n");

§Errors

Returns CompileError for invalid syntax, undefined variables, arithmetic faults, or programs that exceed the instruction limit.

# PyCompiler geliştirme prompt'u

GitHub Copilot Chat bu depoda gerçek skill dosyası olarak
`.github/skills/pycompiler-development/SKILL.md` yolunu kullanır; skill'in
`name` alanı ile klasör adı eşleşir ve bu konum VS Code tarafından keşfedilir.

Proje genelinde her isteğe otomatik uygulanan kısa talimatlar
`.github/copilot-instructions.md` dosyasındadır. Bu dosya, keşif uyumluluğu
için bırakılmış giriş noktasıdır; skill içeriğini burada çoğaltmayın.
